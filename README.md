AWS Amplify React App with Cognito Authentication

This project demonstrates the deployment of a React web application using AWS Amplify for hosting and Amazon Cognito for authentication.
The main focus of this project was to configure and integrate AWS services to deploy a secure, scalable web app through a GitHub repository connection.

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Architecture and Technologies Overview

Frontend Source: React App 

Deployment Platform: AWS Amplify

Backend Service: Amazon Cognito (User Authentication)

Code Repository: GitHub (automatic deployment from main branch)

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Skills & Services Used
AWS Cloud Administration

-Amplify Hosting

	-Connected GitHub repository to AWS Amplify for CI/CD deployment.

	-Configured build settings and environment variables.

	-Verified successful deployment through Amplify console and public URL.

Amazon Cognito

	-Created a User Pool for authentication.

	-Configured App Client and Hosted UI for login and registration.

	-Integrated Cognito with Amplify to enable secure sign-in flow.

IAM (Identity and Access Management)

	-Applied fine-grained permissions for Amplify and Cognito access.

	-Used roles to separate deployment and authentication privileges.

-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Learning Objectives

-Practice deploying frontend applications using AWS Amplify.

-Understand Cognito integration for authentication.

-Gain hands-on experience with GitHub–AWS CI/CD automation.

-Reinforce cloud deployment workflows without local backend setup.
